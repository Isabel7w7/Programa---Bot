# Bot Institucional: Automatizacion de Servicios Escolares

Este proyecto consiste en un **bot institucional basado en reglas**, diseñado para brindar respuestas rápidas a las preguntas más frecuentes dentro de una institución educativa.

El bot presenta al usuario **opciones predefinidas** con información común (trámites, horarios, servicios, etc.).  
En caso de que la consulta no se encuentre disponible o sea más específica, el sistema permite **contactar directamente con la institución educativa a través de Gmail**.

---

## 🎯 Objetivo del proyecto

- Facilitar el acceso a información institucional
- Reducir consultas repetitivas
- Brindar una atención inicial rápida y clara
- Ofrecer un canal de contacto directo para dudas específicas

---

## 🧠 Funcionamiento

- El bot opera mediante un **sistema basado en reglas**
- Muestra opciones con las consultas más comunes
- Responde según la opción seleccionada
- Redirige al correo institucional cuando la consulta no está contemplada

---

## 🛠️ Tecnologías utilizadas

- HTML5  
- CSS3  
- JavaScript  

---

## 📩 Contacto institucional

Si el usuario requiere atención personalizada o una consulta más específica, puede comunicarse con la institución educativa 
mediante una ventana donde el usuario elige un correo de la institución ya proporcionado, en este el usuario escribe su problema y se le solicita su correo electronico 
para que despues la institucion se ponga en contacto con la persona que tiene el problema.
